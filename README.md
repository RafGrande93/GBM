# GBM

What:
  - Model: Simulate asset prices as a Geometric Brownian Motion 
  - Numerics: Use Euler–Maruyama to generate paths and check accuracy against the exact GBM solution. Introduce Monte Carlo Methods.
  - Stats: Measure errors and moments.

Run:
  pip install -r requirements.txt
  jupyter lab
  Open gbm_euler_maruyama.ipynb and run all cells
